# 1st Stands — landing page

Projeto inicial em HTML, CSS e JavaScript puro, responsivo para celular e desktop.

## Como abrir
1. Extraia a pasta.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
3. O portfólio está preparado em `portfolio.html`.

## Ajustes necessários antes de publicar
- `js/main.js`: altere `WHATSAPP_PHONE` para o número oficial com código do país e DDD, somente números. Exemplo: `5511999999999`.
- `js/main.js`: ajuste `WHATSAPP_MESSAGE` se desejar outra mensagem inicial.
- `index.html` e `portfolio.html`: substitua os dados de contato, localização e redes sociais pelos dados oficiais.
- `index.html`: troque o logo textual pela imagem oficial quando estiver disponível.
- `index.html`: substitua as três URLs de imagem do carrossel por fotos reais dos stands. As imagens atuais são apenas referências visuais.
- `index.html`: revise os textos dos serviços para refletir exatamente o que a empresa oferece.
- `portfolio.html`: adicione os projetos quando as fotos estiverem prontas.

## Estrutura
- `index.html` — landing page
- `portfolio.html` — página inicial do portfólio
- `css/style.css` — estilos e responsividade
- `js/main.js` — carrossel, menu mobile, WhatsApp e ano do rodapé
- `assets/images/` — pasta reservada para imagens locais

Observação: o domínio `1ststands.com.br` precisa ser registrado e conectado à hospedagem separadamente.
